A FEW QUICK ANSWERS

Good to know.

What kind of files can I use?

PDFs, Word and PowerPoint files, common text files, and images are supported. Scanned pages and image text can be read using OCR.

Where do the answers come from?

MyDocx.ai searches the text in your uploaded documents and shows relevant source passages alongside its answer.

Can I ask questions without an API key?

Yes. Document search and source passages work locally. Add a Gemini API key in your private .env file to enable generated answers.
